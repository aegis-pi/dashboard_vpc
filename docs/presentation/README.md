## 기준

- 발표 문서는 운영 문서와 계획 문서를 요약하는 용도로 둔다.
- 세부 명령, 민감 정보, 임시 credential은 포함하지 않는다.
- 현재 완료/활성 상태와 후속 목표를 분리해 적는다. Data/Dashboard 일시 root는 데모 전 build가 필요한 운영 패턴이다.
